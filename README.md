# OZON图片批处理工具

## 项目简介

这是一个专为OZON电商平台设计的图片批处理工具，可以自动处理大量图片，包括尺寸调整、水印添加、噪点处理等功能。

## 主要功能

- 🖼️ 批量处理图片文件（支持jpg、jpeg、png、tif、psd、webp格式）
- 📏 智能尺寸调整（3:4和1:1比例）
- 💧 自动添加水印（支持实时控制）
- 🎨 随机亮度调整和噪点添加
- 🔄 轻微旋转处理
- 📊 实时进度显示
- 🖥️ 现代化GUI界面
- 🎛️ 水印参数实时调节（文字、透明度、字体大小、颜色）

## 文件说明

- `process_images_gui.py` - 主程序文件（GUI版本）
- `process_images.py` - 原始命令行版本
- `requirements.txt` - Python依赖包列表
- `ozon_processor.spec` - PyInstaller配置文件
- `build_exe.bat` - Windows批处理打包脚本
- `build_exe.ps1` - PowerShell打包脚本

## 安装和运行

### 方法1：直接运行Python脚本

1. 确保已安装Python 3.7+
2. 安装依赖包：
   ```bash
   pip install -r requirements.txt
   ```
3. 运行程序：
   ```bash
   python process_images_gui.py
   ```

### 方法2：打包成exe文件

1. 运行打包脚本：
   - Windows: 双击 `build_exe.bat`
   - PowerShell: 右键选择"使用PowerShell运行" `build_exe.ps1`

2. 等待打包完成，exe文件将生成在 `dist` 文件夹中

3. 将生成的exe文件复制到其他电脑即可运行（无需安装Python）

## 使用说明

1. 启动程序后，点击"浏览"按钮选择包含图片的文件夹
2. 点击"开始处理"按钮开始批量处理
3. 程序会自动创建 `JPEG-Treated-Python` 子文件夹存放处理后的图片
4. 处理过程中可以查看实时进度和日志信息

## 配置选项

可以在 `process_images_gui.py` 文件顶部修改以下配置，或者在GUI界面中实时调整：

### 默认配置（代码中设置）
```python
# 水印设置
TEXT_WATERMARK_CONTENT = "Kaqiusha"        # 水印文字
TEXT_WATERMARK_OPACITY = 3                 # 水印透明度
TEXT_WATERMARK_FONT_SIZE = 24              # 字体大小
TEXT_WATERMARK_COLOR = (128, 128, 128)     # 水印颜色

# 输出文件夹名称
OUTPUT_SUBFOLDER_NAME = "JPEG-Treated-Python"

# 目标尺寸
SIZES_3_4 = [(900, 1200), (1200, 1600), (1500, 2000)]  # 3:4比例
SIZES_1_1 = [(800, 800), (1000, 1000), (1200, 1200), (1600, 1600)]  # 1:1比例
```

### GUI界面实时控制
程序提供了友好的水印设置面板，您可以：
- 📝 直接编辑水印文字内容
- 🎚️ 使用滑块调节透明度（1%-100%）
- 🔤 设置字体大小（8-72像素）
- 🎨 分别调节RGB颜色值（0-255）
- 👁️ 实时预览颜色效果

所有设置都是实时生效的，无需重启程序！

## 系统要求

- Windows 7/8/10/11
- 至少2GB内存
- 支持常见图片格式

## 注意事项

1. 程序会自动跳过不符合3:4或1:1比例的图片
2. 处理后的图片将保存为JPEG格式，质量设置为95%
3. 原始图片不会被修改，处理后的图片保存在新建的子文件夹中
4. 建议在处理大量图片前先备份原始文件

## 故障排除

### 常见问题

1. **程序无法启动**
   - 检查是否安装了所有依赖包
   - 确保Python版本为3.7或更高

2. **图片处理失败**
   - 检查图片文件是否损坏
   - 确保图片格式受支持
   - 检查磁盘空间是否充足

3. **打包失败**
   - 确保已安装PyInstaller：`pip install pyinstaller`
   - 检查Python环境变量设置
